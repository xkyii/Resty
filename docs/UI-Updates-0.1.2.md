# UI 更新文档 - 0.1.2 版本

**版本**: 0.1.2

**主题**: 侧边栏交互优化 + 历史记录详情展示

## 1. 侧边栏顶部菜单栏改动

### 1.1 工作区模式

**旧设计**:
```
┌─────────────────────────────────────┐
│ [☰] [◎]                             │
│ ─────────────────────────────────── │
│ [搜索请求…]                          │
│ ▾ users.http                        │
│   ├ GET  Get User                   │
│   └ POST Create User                │
└─────────────────────────────────────┘
```

**新设计**:
```
┌──────────────────────────────────────┐
│ [☰] [◎]  [▼ 操作]                   │
│ ───────────────────────────────────│
│ [搜索请求…]                          │
│ ▾ users.http                        │
│   ├ GET  Get User                   │
│   └ POST Create User                │
└──────────────────────────────────────┘

[▼ 操作] 按钮点击弹出菜单：
┌──────────────┐
│ ✓ 新建 HTTP  │
│ ☑ 跟随打开   │
└──────────────┘
```

**按钮规格**:
- 宽度: 88px（包含文字 + 箭头）
- 高度: 32px（与 Tab 按钮一致）
- 样式: 图标 + 文字 + 下拉箭头
- 位置: Tab 行右侧

**功能**:
- **新建 HTTP**: 点击后弹出文件名输入框，创建新 .http 文件
- **跟随打开**:
  - Toggle 选项（显示复选框 ☑ 或 ☐）
  - 启用时：当 Tab 激活时，左侧边栏自动高亮对应请求
  - 禁用时：左侧边栏不随 Tab 变化

### 1.2 环境模式

**旧设计**:
```
┌─────────────────────────────────────┐
│ [☰] [◎]                             │
│ ─────────────────────────────────── │
│ 环境                           [+]  │
│ ─────────────────────────────────── │
│ ● dev                          […] │
│ ○ prod                         […] │
│ ○ staging                      […] │
└─────────────────────────────────────┘
```

**新设计**:
```
┌──────────────────────────────────────┐
│ [☰] [◎]  [▼ 操作]                   │
│ ───────────────────────────────────│
│ ● dev                               │
│ ○ prod                              │
│ ○ staging                           │
└──────────────────────────────────────┘

[▼ 操作] 按钮点击弹出菜单：
┌──────────────┐
│ + 新建环境   │
└──────────────┘
```

**变更**:
- 移除"环境"标题
- 移除标题右侧的"+"按钮
- 新建环境功能迁移到右侧菜单按钮
- 环境列表直接显示，顶部留出合理的 padding

### 1.3 按钮实现细节

**共同样式**:
```
[▼ 操作]
图标: ▼ (下拉三角)
文字: "操作"
字体: 11px，TextSec 颜色
背景: 透明（Hover 时 BgHover）
Margin: 0px (紧靠 Tab 按钮)
高度: 32px
```

**实现位置**: `SidebarView.cs` - Tab 行布局中

## 2. 右键菜单重组

### 2.1 http 文件右键菜单

**变更项**:

| 项目 | 旧状态 | 新状态 | 说明 |
|------|--------|--------|------|
| 新建请求 | ✗ | ✓ | 新增，排第1位 |
| 在资源管理器打开 | ✓ | ✓ | 保持，排第2位 |
| 复制路径 | ✓ | ✓ | 保持，排第3位 |

**菜单结构**:
```
┌──────────────────────────────────┐
│ 新建请求                          │ ← NEW (分隔线上)
├──────────────────────────────────┤
│ 在资源管理器中打开                 │
│ 复制路径                          │
└──────────────────────────────────┘
```

**新建请求交互流程**:
1. 右键点击 http 文件 → 选择"新建请求"
2. 弹出对话框，输入请求名称（如 "Get User"）
3. 点击确认 → 在文件末尾追加：
   ```
   ### Get User
   GET https://example.com
   ```
4. 文件自动保存
5. 编辑器自动打开新请求的标签页

### 2.2 请求行右键菜单

**变更项**:

| 项目 | 旧状态 | 新状态 | 说明 |
|------|--------|--------|------|
| 打开 | ✓ | ✗ | 删除，单击已支持打开 |
| 复制请求名称 | ✓ | ✓ | 保持 |

**菜单结构**:
```
┌──────────────────────────────────┐
│ 复制请求名称                      │
└──────────────────────────────────┘
```

**说明**: 单击请求行已触发 RequestSelected 事件打开编辑器，无需菜单项重复。

### 2.3 环境变量行右键菜单

**变更项**:

| 项目 | 旧状态 | 新状态 | 说明 |
|------|--------|--------|------|
| ...按钮 | ✓ 按钮 | ✗ | 移除右侧"..."按钮 |
| 重命名 | ✗ | ✓ 菜单 | 新增菜单项 |
| 删除 | ✓ 菜单 | ✓ 菜单 | 保持菜单项 |

**菜单结构**:
```
┌──────────────────────────────────┐
│ 重命名                            │ ← NEW
├──────────────────────────────────┤
│ 删除                              │
└──────────────────────────────────┘
```

**重命名交互流程**:
1. 右键点击环境名（如 "dev"）→ 选择"重命名"
2. 环境行转变为编辑模式，显示输入框
3. 输入新名称 → 点击确认（✓ 按钮）或回车
4. 后端操作：
   - 更新 `http-client.env.json` 中的 key
   - 更新 `http-client.private.env.json` 中的 key（如果存在）
5. UI 刷新显示新名称

## 3. 请求历史面板改动

### 3.1 布局变更

**旧设计** - 仅列表：
```
┌──────────────────────────────────┐
│ 请求历史              [清除]      │
├──────────────────────────────────┤
│ [GET  200  2m前]                  │
│  api.example.com/users            │
│  Get-User                         │
├──────────────────────────────────┤
│ [POST 201  5m前]                  │
│  api.example.com/users            │
│  Create-User                      │
└──────────────────────────────────┘
```

**新设计** - 左右两栏：
```
┌──────────────────────────────────────────────┐
│ 请求历史 [清除]  │  请求详情                 │
├──────────────┬──────────────────────────────┤
│              │ 请求摘要                      │
│ [GET 200..] │ ├─ 文件夹: samples           │
│ [POST 201.] │ ├─ 文件: users.http          │
│ [GET 200..] │ ├─ 请求: Get User           │
│              │ ├─ 时间: 2 分钟前             │
│              │ ├─ 方法: GET                 │
│              │ ├─ URL: https://...          │
│              │ ├─ 状态: 200 OK              │
│              │ ├─ 耗时: 45ms                │
│              │ └─ 大小: 1.2KB               │
│              ├──────────────────────────────┤
│              │ 原始请求                      │
│              │ ├─ GET /api/users/1 HTTP/1.1 │
│              │ ├─ Host: api.example.com      │
│              │ ├─ Authorization: Bearer...  │
│              │ └─ ...                        │
│              ├──────────────────────────────┤
│              │ [复制请求] [在编辑器打开]     │
└──────────────┴──────────────────────────────┘
```

**布局规格**:
- 左栏宽度: 160px（固定或可调整）
- Splitter 厚度: 4px
- 右栏宽度: 剩余空间
- 分隔线颜色: BorderCol

### 3.2 历史列表项

**选中状态**:
- 背景色: BgActive（蓝色）
- 文字色: TextPri

**列表项内容**（保持现有）:
```
[GET  200  2m前]  api.example.com/users
 Get-User
```

### 3.3 右侧详情面板

#### 摘要部分

显示选中请求的关键信息（类似 Badge 风格）：

```
文件夹:  samples
文件:    users.http
请求:    Get User
时间:    2 分钟前
方法:    GET (配色同方法标签)
URL:     https://api.example.com/api/users/1
状态:    200 OK (配色：2xx 绿色)
耗时:    45ms
大小:    1.2KB
```

**样式**:
- 标签颜色: TextSec
- 值颜色: TextPri
- 行距: 6px
- Padding: 12px（上下左右）
- 字体: 12px (标签) / 13px (值)

#### 原始请求部分

显示该历史记录保存的原始请求文本：

```
GET /api/users/1 HTTP/1.1
Host: api.example.com
Authorization: Bearer {{token}}
Accept: application/json

(No body)
```

**样式**:
- 字体: Monospace 11px
- 背景: BgBase（深色）
- Padding: 8px
- 行高: 1.5
- 可复制（Ctrl+C）

#### 操作按钮区

```
[复制请求]  [在编辑器打开]
```

**按钮样式**:
- 尺寸: 高 28px
- 宽度: 自适应（约 60-80px）
- 背景: BgPanel
- Hover: BgHover
- 间距: 8px

**功能**:
- 复制请求: 将原始请求文本复制到剪贴板
- 在编辑器打开:
  - 读取该历史项关联的源文件
  - 定位到对应请求
  - 在编辑器打开新标签页

### 3.4 数据结构扩展

**HistoryEntry 新增字段**:

```csharp
public sealed record HistoryEntry(
    string RequestName,
    string Method,
    string Url,
    int StatusCode,
    long ElapsedMs,
    DateTime Timestamp,
    string FilePath,           // NEW: 源文件路径
    string RequestText,        // NEW: 原始请求文本
    string FolderPath = ""     // NEW: 文件夹路径（可选，从 FilePath 推导）
);
```

**JSON 序列化示例**:
```json
{
  "requestName": "Get User",
  "method": "GET",
  "url": "https://api.example.com/api/users/1",
  "statusCode": 200,
  "elapsedMs": 45,
  "timestamp": "2026-05-07T10:30:00Z",
  "filePath": "D:\\workspace\\samples\\users.http",
  "requestText": "GET /api/users/1 HTTP/1.1\r\nHost: api.example.com\r\n...",
  "folderPath": "samples"
}
```

**兼容性**:
- 旧版本历史记录（无新字段）自动升级
- 字段缺失时用默认值（空字符串）

## 4. 交互流程总结

### 流程 1：切换工作区模式并新建 HTTP

```
1. 用户点击 [☰] Tab 切换到工作区模式
2. 点击右侧 [▼ 操作] 按钮
3. 菜单弹出，显示"新建 HTTP"、"跟随打开"
4. 点击"新建 HTTP"
5. 弹出文件名输入对话框
6. 输入文件名（如 "products"）→ 自动补充 .http 后缀
7. 点击确认
8. 文件创建在工作区根目录
9. 左侧树形图自动刷新，显示新文件
10. 新文件自动打开第一个请求的编辑器标签
```

### 流程 2：在 http 文件中新建请求

```
1. 用户在左侧找到 users.http 文件
2. 右键点击文件名
3. 菜单弹出，第一项是"新建请求"
4. 点击"新建请求"
5. 对话框弹出，输入请求名（如 "Delete User"）
6. 点击确认
7. 新请求追加到文件末尾
8. 编辑器自动打开该请求的标签页
```

### 流程 3：重命名环境

```
1. 用户点击 [◎] Tab 切换到环境模式
2. 在环境列表中找到"dev"
3. 右键点击"dev"
4. 菜单弹出，选择"重命名"
5. "dev"行变成编辑模式，显示输入框，内容为"dev"
6. 清除并输入新名称（如 "development"）
7. 点击 ✓ 按钮或按回车
8. 后端更新两个 env.json 文件
9. UI 刷新，显示新环境名"development"
```

### 流程 4：查看历史记录详情

```
1. 用户点击 Activity Bar 中的 [⧗] 切换到历史面板
2. 左侧列表显示最近请求（保持现状）
3. 点击某个历史项（如"Get User"）
4. 右侧详情面板显示：
   - 文件夹、文件、请求名、时间等摘要
   - 原始请求文本（GET /api/users/1 HTTP/1.1 等）
5. 用户可点击"复制请求"按钮复制文本到剪贴板
6. 或点击"在编辑器打开"打开该请求的编辑器标签
```
