### 2.4 标签页（Tab）

```
┌──────────────────────┬───────────────────┬───┐
│  ● GET /users        │  POST /users  ✕   │ + │
│  (active)            │                   │   │
```

- 激活标签：背景 `#1E1E1E`，底部 2px 线 `#007ACC`，文字 `#CCCCCC`

- 关闭按钮 `✕`：Hover 时显示，图标 12px
- 新建 `+`：固定在标签栏右端

- 悬停：背景 `#2A2D2E`

### 3.4 交互流程

1. 点击「打开工作区文件夹」→ 调用系统 FolderPicker 对话框
2. 用户选择文件夹 → 写入 `%APPDATA%\Resty\workspaces.json` → 切换至主界面
3. 点击最近列表项 → 直接切换至主界面
4. 点击列表项右侧 `✕` → 从列表移除（无确认，可撤销 Toast）
