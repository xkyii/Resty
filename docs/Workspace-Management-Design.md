# 工作区管理设计（最近 + 收藏）

## 1. 背景与目标

当前“最近工作区”仅提供单列表快速切换，无法满足以下需求：
- 对工作区进行收藏管理。
- 在一个统一入口完成查找、筛选、查看详情和打开。
- 控制“最近工作区”展示数量（默认 5，可配置）。

本设计将 Activity Bar 第三项从“最近工作区”升级为“工作区管理”，并拆分为“最近 + 收藏”两部分。

## 2. 设计范围

本次范围包含：
- 左侧导航面板结构升级：头部、搜索、最近分组、收藏分组。
- 右侧详情面板：展示选中工作区信息（路径、HTTP 文件数、请求数等）。
- 数据持久化：最近、收藏、显示数量配置。
- 与主窗口联动：左侧选中更新右侧详情，右侧操作触发打开与收藏状态变更。

本次不包含：
- 收藏分组手动排序。
- 工作区缩略图/封面。
- 复杂统计缓存与增量刷新（采用即时扫描即可）。

## 3. 信息架构

### 3.1 Activity Bar
- 文案：工作区管理
- 图标：沿用当前工作区图标（首版不改）

### 3.2 左侧面板结构（自上而下）
1. 统一头部：标题“工作区管理”。
2. 搜索框：按名称/路径过滤。
3. 最近工作区分组：固定显示 N 条（默认 5，配置项）。
4. 收藏工作区分组：显示全部收藏。

### 3.3 右侧内容
- 未选中：空态提示。
- 选中后：详情卡片 + 操作按钮。

## 4. 交互设计

### 4.1 左侧列表交互
- 单击列表项：仅更新右侧详情，不立即切换工作区。
- 双击列表项：直接打开该工作区。
- 悬浮：背景高亮。
- 当前已打开工作区：高亮文字/标记。

### 4.2 右侧详情操作
- 打开工作区（当前工作区显示“重新加载”）。
- 收藏 / 取消收藏。
- 从最近移除。
- 在系统资源管理器中打开目录。

### 4.3 搜索与过滤
- 统一搜索框过滤“最近”和“收藏”两个分组。
- 过滤命中规则：不区分大小写，名称或完整路径包含关键词。
- 分组标题固定可见；分组无结果显示“无匹配项”。

## 5. 数据模型与持久化

### 5.1 工作区条目模型（视图层）
- Path: string
- Name: string
- IsFavorite: bool
- Exists: bool
- HttpFileCount: int
- RequestCount: int
- LastAccessedAt: DateTime?

### 5.2 最近工作区存储
文件：`%APPDATA%/Resty/recent_workspaces.json`

结构（扩展后）：
```json
[
  {
    "path": "D:\\Code\\ProjectA",
    "lastAccessedAt": "2026-05-08T10:30:00Z"
  }
]
```

兼容策略：
- 若读取到旧格式 `string[]`，自动升级到新格式并保存。

### 5.3 收藏工作区存储
文件：`%APPDATA%/Resty/favorite_workspaces.json`

结构：
```json
[
  "D:\\Code\\ProjectA",
  "D:\\Code\\ProjectB"
]
```

### 5.4 设置项（显示数量）
文件：`%APPDATA%/Resty/settings.json`

新增字段：
- `RecentWorkspaceDisplayCount: int = 5`

约束：
- 范围 3~20，越界回退 5。

## 6. 统计规则

对选中目录进行即时扫描：
- `HttpFileCount`：递归统计 `*.http` 文件数。
- `RequestCount`：对每个 `*.http` 文件执行解析，累加请求数量；解析失败文件记为 0 并继续。

异常策略：
- 路径不存在：`Exists=false`，统计显示 `-`。
- 扫描异常：显示“统计失败”，不阻塞“打开工作区”操作。

## 7. 实现切片

### Slice A（本次）
- 新增收藏服务与最近服务扩展（含旧数据兼容）。
- 重构工作区管理面板（左侧结构 + 右侧详情）。
- 主窗口接线：列表选中、打开、收藏切换、从最近移除。
- 设置项新增“最近显示数量”。

### Slice B（后续可选）
- 收藏拖拽排序。
- 统计缓存与后台刷新。
- 失效路径批量清理。

## 8. 验收标准

- Activity Bar 第三项标题与窗口标题均为“工作区管理”。
- 左侧展示头部 + 搜索 + 最近（默认 5）+ 收藏。
- 选中列表项后，右侧展示路径、HTTP 文件数、请求数。
- 支持收藏/取消收藏、从最近移除、打开目录。
- 设置项可配置最近显示数量并生效。
- 兼容旧版 recent 数据格式。
