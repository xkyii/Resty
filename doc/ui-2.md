

## 总体要求
- 无边框

## 通用标题栏
- icon1: (靠左) App图标
- File: (靠左) 包含`偏好配置`和`退出`
- icon2: (居中) 切换按钮, 用于切换`目录管理`和`工作区`
- text1: (居中) 显示当前工作区名称(目录名)
- icon3: (居中) 下拉框按钮, 用于快速切换工作区
- min: (靠右) 最小化
- max: (靠右) 最大化
- close: (靠右) 关闭


## 目录管理

```text
┌────────────────────────────────────────────────────────────────────────────┐
│[icon1] [file] [help]       [icon2][text1][icon2]          [min][max][close]│

│ 搜索"最近"或"目录"     │     [toolbar]                                      │
├───────────────────────┬────────────────────────────────────────────────────┤
│                       │    dir infomation                                  │

│   dir1                │                                                    │
│   dir2                │                                                    │
│   dir3                │                                                    │
│ 目录                  │                                                    │
│   dir1                │                                                    │
│   dir2                │                                                    │
│   dir3                │                                                    │

```


### 界面组成
- 通用标题栏
- 左侧面板：
	- 顶部搜索框（提示：“搜索 '最近' 或 '目录'”, 共用）；
	- (导航栏) 两个根分组的树形列表：根节点“最近”和“目录”，每项可展开显示子目录或条目。
- 右侧主区上部：工具栏
    - (靠右) 按钮: "打开目录"
    - 选中"最近"的项目时, (靠左) "在资源管理器中打开", "移除", "加入目录管理"等
    - 选中"目录"的项目时, (靠左) "在资源管理器中打开", "移除"等
- 右侧主区下部:
    - 显示被选中目录的元信息


## 工作区

```text
┌────────────────────────────────────────────────────────────────────────────┐
│[icon1] [File] [Help]       [icon2][text1][icon3]          [min][max][close]│
├───────────────────────┬────────────────────────────────────────────────────┤
│ 搜索"集合"或"历史"     │   [tabbar]                                         │
├───────────────────────┬────────────────────────────────────────────────────┤
│   [icon4] [icon5]     │  集合名/[request]                   [save][refresh] │
├───────────────────────┬ [Method][Url]                                [Send]│
│                       │ [Queries][Headers][Body][Auth]                     │
│ 集合名                 │                                                    │
│   request1            │                                                    │
│   request2            │                                                    │
│   request3            ┬────────────────────────────────────────────────────┤
│   request4            │ [code][time cost][size]    [Body][Headers][Cookies]│
│   request5            │                                                    │
│   request6            │       content                                      │
└───────────────────────┴────────────────────────────────────────────────────┘
```


### 界面组成
- 通用标题栏
- 左侧面板：
	- 顶部搜索框（提示：“搜索 '集合' 或 '历史'”）；
    - 接顶部, 两个图标, 分别用于切换"集合"或"历史"
	- (导航栏) 树形列表, 当切换到"集合"时, 显示请求列表; 当切换到"历史"时, 显示请求历史记录

#### 选中请求时
- 右侧主区上部：TabControl (请求名称)
- 右侧主区中部部: (请求内容)
    - 第一行:
        - (靠左, 不可编辑) 集合名
        - (靠左, 可编辑) 请求名
        - (靠右) "保存"按钮
        - (靠右) "刷新"按钮
    - 第二行:
        - (靠左, 下拉框), 请求方法 (GET/POST/DELETE/PUT/PATCH等)
        - (靠左, 可编辑), 请求地址
    - 第三行:
        - TabControl, 四个标签: Queries,Headers,Body,Auth
    - 主体:
        - 当选中`Queries`, 显示请求参数列表
        - 当选中`Headers`, 显示请求头列表
        - 当选中`Body`, 显示请求体内容
        - 当选中`Auth`, 显示请求认证信息
- 右侧主区中部部: (响应内容)
    - 第一行:
        - (靠左) 响应码
        - (靠左) 响应时间
        - (靠左) 响应体大小
        - (靠右, 三个按钮) Body, Headers, Cookies
    - 主体:
        - 当选中Body时, 显示响应体内容
        - 当选中Headers时, 显示响应头内容
        - 当选中Cookies时, 显示Cookies内容
